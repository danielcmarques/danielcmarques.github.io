I developed and taught the "Operating System Fundamentals and Administration" postgraduate certificate course at [Instituto Infnet](https://www.infnet.edu.br) from 2012 to 2014. This course covers foundational and practical aspects of managing operating systems. It used Linux as a primary example, with courseware algined with the LPIC-1 certification objectives. The course also offered contrasting views between Linux and Windows, covering topics such as managing files and directories, using the VI editor, and understanding the structure of the operating system. Learners will work with the Linux file system, install and configure distributions, manage users and groups, and handle processes. They will explore hardware and architecture requirements, install package managers, use GNU and Unix commands, and integrate new devices into a Linux environment. The curriculum also includes implementing the Filesystem Hierarchy Standard, working with graphical applications, and understanding the differences between the X Window System and other environments. 

I personally developed all the courseware for this class.
