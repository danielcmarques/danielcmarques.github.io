I developed and taught the "Advanced Operating System Administration" postgraduate certificate course at [Instituto Infnet](https://www.infnet.edu.br) from 2012 to 2014. This course covered advanced topics related to operating systems administration in networked environments. Using Linux to support the classroom lab activities, students worked through customizing and using the shell environment, as well as creating simple scripts to automate tasks. The course covered SQL data administration, installation and configuration of X11, and management of graphical desktops. Learners gained hands-on experience in implementing and managing user accounts, automating and scheduling tasks, maintaining system date and time routines, and configuring and analyzing log files. The curriculum included understanding mail transfer agent (MTA) fundamentals, configuring printers, and learning the principles of Internet protocols.

In the networking section, students implemented basic network configurations, troubleshooted common networking issues, configured DNS clients, and performed security-related administrative tasks. 

Additionally, the course covered host security best practices, such as hardening, and strategies for protecting data through encryption in Linux environments.

I developed customized courseware to support the learning objectives of this class.
